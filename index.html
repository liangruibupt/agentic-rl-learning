Agentic RL 学习课程

从“什么是强化学习”讲到“在 AWS 上设计一个可复现的智能体 RL 实验”。每一页都有可以动手的交互组件：拖滑块、点步骤、切换模式、做小测验。

一句话定义：Agentic RL（智能体强化学习）是让大模型以智能体身份在环境中多轮调用工具、观察结果、继续决策，最后按任务结果打分，再用强化学习更新模型参数。它训练的是“一整条把事情办成的决策轨迹”，不只是“一句更好的回答”。

三种后训练方式对比

SFT 监督微调单轮 RL（RLHF / RLVR / RFT）Agentic RL（多轮 RL）
学什么模仿标注答案对单个 prompt 产出高分回答多步决策：何时调哪个工具、如何根据反馈调整
需要的数据输入 + 标准输出prompt + 打分器任务 + 环境 + 打分器（不需要标准轨迹）
一个样本一段文本一个回答一条多轮轨迹（几十轮，几分钟到几小时）
主要难点数据质量奖励设计、奖励作弊以上全部 + 环境工程、长程信用分配、并发沙箱、训推一致

学习路线

基础班建立直觉
  1. 什么是 Agentic RL：把 LLM 看成策略，单轮和多轮的本质区别
  2. 一次训练迭代：从取任务到权重同步的 8 个步骤
  3. GRPO 入门：组内比较怎样产生学习信号

前置知识：会用大模型 API，知道什么是微调。

中级班能设计训练
  1. 奖励设计：复现一个真实的奖励作弊案例
  2. 多轮训练关键技术：loss mask、信用分配、训推一致、冷启动

学完能判断一个业务任务适不适合 RL，并写出第一版奖励函数。

进阶班理解系统与生态
  1. 算法家族：PPO、GRPO、DAPO、Dr.GRPO、GSPO、CISPO
  2. 系统架构与异步 rollout
  3. 前沿玩家与方案提供方

学完能和客户的算法团队讨论框架选型。

落地班动手做
  1. 客户自建：选型向导、路线图、成本估算器
  2. AWS 实验设计：AgentCore + SageMaker AI 多轮 RL + Bedrock

学完能给客户出一份可执行的 PoC 方案。

本课程内容基于截至 2026-11 的公开资料。产品支持的模型、区域和价格变化很快，落地前以官方文档为准。
